# Dynamic Maze

A puzzle game featuring a constantly shifting maze where the player must navigate through changing walls to reach the exit before time runs out.

## How to Play

1. Use the arrow keys or WASD to move your character (green circle)
2. Navigate through the shifting maze to reach the exit (blue square)
3. Avoid the enemy (red circle) that chases you
4. Complete each level before the timer runs out
5. The maze will shift randomly after each move, creating new paths and obstacles
6. Each level becomes progressively more difficult

## Game Features

- Dynamic maze generation with walls that shift as you move
- AI enemy that pursues the player
- Timer that counts down, adding urgency to gameplay
- Progressively difficult levels
- Obstacles that block your path

## Technologies Used

- HTML5
- CSS3 with animations
- Vanilla JavaScript

## Installation

No installation required! Simply open the `index.html` file in a web browser to play.
